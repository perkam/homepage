# Homepage design document
## Goals
- Easy to update - adding new article should require adding new markdown page in a directory.
- Pretty code snippets with syntax highlight.
- Comments like these: ![./docs/img.png](img.png)
- Easy to find via search browser - good SEO.
- Permanent About Me page.
- Tags and ability to display articles with some tag
- Good mobile experience
- Readers can share articles
- Articles can be easily shared on social media
- RSS
- I can embed things like youtube videos etc.
## Anti-goals
- Not a documentation page
- Only about me will be used as promotional page
- No users comments - contact through social media/email only
